### 1.2 The Mission — Career OS
From CEO Ben Ho:
> "Career OS is our attempt to change that. Not to predict anyone's future — careers are too messy and too lucky for that — but to give people a better view of the landscape they're already in. A navigation tool that respects that the person using it gets to choose."

Career OS is a **navigation tool, not a prediction tool.** It should help users:
- See the landscape, not a single answer — surface realistic range of trajectories
- Understand career as continuous, not transactional — a 40-year arc
- Speak human language back — explain why a recommendation makes sense, where uncertainty sits
- Connect both sides honestly — candidates findable at the right moment, employers finding the right person before they're publicly looking

**Career lifecycle Career OS serves:**
- Age 15–17 (Student): Discover paths, choose streams, early skills

**Four dimensions Career OS must address:**
1. **Discovery** — the right match at the right time, beyond keyword matching
2. **Growth** — surface skill gaps, learning paths, moves that compound value
3. **Progression** — map likely trajectories, help users decide at the right moment
4. **Feedback** — close the gap between applications, interviews, and outcomes

## PART 3: THE PRODUCT — SIGNALMAP

### 3.1 What It Is
**SignalMap** is a real-time AI-powered talent demand intelligence platform built as a Career OS module. It maps what skills Malaysian employers are actually hiring for — by industry, city, and salary band — and surfaces that intelligence as an interactive dashboard serving candidates, employers, and Talentbank simultaneously.

**Tagline:** *"See what Malaysia is hiring for. Know where you fit."*

### 3.2 The Problem
Malaysia produces 300,000+ graduates annually. Over 48% are overqualified for the jobs they take — not from lack of talent but lack of real-time market visibility. Graduates apply blindly. Employers post jobs without knowing if the talent supply exists. No platform in Malaysia shows the real-time skill demand map. SignalMap closes this information gap. (Validated by KRI research, Malay Mail reporting, RM 3B government reskilling allocation.)

### 3.3 The Three Product Views

**View 1 — Demand Map**
Interactive dashboard: which skills employers need right now.
Filters: Industry (Tech/Finance/Healthcare/Engineering/Education/Other), City (KL/Selangor/Penang/Johor/Remote), Seniority (Junior/Mid/Senior/Lead), Time window (7d/30d/90d).
Visualized as horizontal bar chart (Recharts) of top 20 skills by posting count.

**View 2 — Salary Intelligence Layer**
Each skill cluster annotated with salary band data extracted from job postings. Transparent, data-backed benchmarks by industry and city.

**View 3 — Personal Fit Analyser**
Candidate inputs current skills → AI analyses gap → returns:
- Match score (0–100)
- Matched skills
- Missing high-demand skills (ranked, with estimated learning time)
- Top 3 recommended roles (with salary ranges)
- Narrative market positioning summary

### 3.4 Why SignalMap Wins This Hackathon

Against the 5 judging criteria:
| Criterion | SignalMap's answer |
|---|---|
| Product & UX Thinking (30%) | Solves the real Malaysian grad overqualification crisis. User journey: type skills → see fit score → know what to learn next |
| System Design & Integration (25%) | Data pipeline → AI extraction → API routes → dashboard. Clean Next.js architecture directly integrable into Talentbank's stack |
| Completeness (20%) | Full end-to-end: data in → intelligence out → candidate takes action. Live on Vercel |
| AI Craft (15%) | OpenRouter powers both JD extraction (structured skill vectors) and candidate fit analysis (personalised narrative). AI is the core, not a feature |
| Code Quality (10%) | TypeScript strict, clean component architecture, documented API routes, Vercel preview deploys |

**Why it fits Career OS strategically:** SignalMap generates the structured talent graph data that makes every other Career OS module smarter. It's the intelligence layer underneath Career OS, not a feature on top. It serves all three sides: candidates (navigate toward real demand), employers (see talent supply), Talentbank (proprietary data asset that compounds in value).

### 3.5 Why We Chose SignalMap (the 5 ideas we evaluated)

| Idea | Rejected because |
|---|---|
| MatchSignal (JD ↔ resume gap) | Too common — dozens of open source clones. Would blend in. |
| TrustHire (verified skills badges) | "Who trusts this badge?" hard to overcome in prototype. Needs network effects. |
| CareerPath AI (backwards career planner) | Good but only serves candidates. Doesn't feed employer side or Talentbank's data needs. |
| InterviewIQ (AI interview coach) | Most crowded space globally. Hard to differentiate. |
| **SignalMap (demand intelligence)** | ✅ CHOSEN — highest strategic fit, most unique, only one that generates the talent graph data Talentbank needs |

**Key stack notes for any new agent:**
- Brand colors are CSS custom properties: `text-brand-primary` (#3730A3), `bg-brand-teal` (#0D9488), `text-brand-rising` (#16A34A), `text-brand-falling` (#DC2626), `text-brand-stable` (#64748B), `bg-brand-bg` (#F8FAFC)
- All shared types: import ONLY from `@/lib/types` — never duplicate
- AI client: `claudeClient` from `@/lib/claude/client` — it's an OpenAI SDK instance pointing to OpenRouter, not Anthropic
- API routes use Web APIs: `Request`/`Response`, `Response.json(body)` — no NextResponse
- `response_format: { type: 'json_object' }` — use this on all AI calls for reliable JSON output
- API responses: `completion.choices[0]?.message?.content` — OpenAI SDK format (not `message.content[0].text`)
- No database for P0 — JSON files in `lib/data/`, bundled via resolveJsonModule

**OpenRouter config (`lib/claude/client.ts`):**
```typescript
import OpenAI from 'openai'
export const claudeClient = new OpenAI({
  apiKey: process.env.OPENROUTER_API_KEY ?? 'not-configured',
  baseURL: 'https://openrouter.ai/api/v1',
  defaultHeaders: {
    'HTTP-Referer': process.env.NEXT_PUBLIC_APP_URL ?? 'https://signalmap.vercel.app',
    'X-Title': 'SignalMap — Malaysian Talent Intelligence',
  },
})
export const AI_MODELS = {
  extraction: 'openai/gpt-4o-mini',
  analysis: 'openai/gpt-4o',
} as const
```

**Environment variables:**
- `OPENROUTER_API_KEY` — set in `.env.local` locally; set as Vercel env var (Sensitive) in production
- `NEXT_PUBLIC_APP_URL` — `http://localhost:3000` locally; `https://signal-map-silk.vercel.app` in production
- `.env.local` is gitignored via `.env*` pattern — never commit API keys

**Golden rule:** Agents never touch each other's files. Coordinate only through CHECKLIST.md.

### 6.2 How to Start a New Agent Session
1. Open Claude Code terminal in the SignalMap project root (`signalmap/`)
2. Paste full contents of `SUPER_PROMPT.md`
3. Add: *"You are Agent [A/B/C/D]. Read your section in AGENT_BRIEFS.md."*
4. Agent reads CLAUDE.md + PRD.md + CHECKLIST.md + its section from AGENT_BRIEFS.md
5. Agent finds first unchecked item in its section and starts
